# AGENTS.md

## Current state

Rust → WebAssembly (wasm-bindgen / web-sys) проект — god-game «имитация жизни».
Сборка и dev-сервер: Trunk 0.21.x. Рендер — Canvas 2D. Ветка по умолчанию: `main`.

Все 26 пунктов дорожной карты реализованы. 89 юнит-тестов. Баланс оттюнен (начальные запасы 200/200,自动建筑 по приоритету, 4 семьи на город, переподготовка ролей).

## Commands

- `cargo check` — быстрая проверка типов (host target)
- `cargo test` — 89 юнит-тестов (детерминизм, ресурсы, строительство, роли, животные, торговля, религия, болезни, укрепления, жизненный цикл, империи, миграция, дипломатия, наука, погода, сейв/лоад)
- `trunk build --release` — production-сборка в `dist/`
- `trunk serve` — dev-сервер с live-reload на http://localhost:8080

## Conventions

- Стек: Rust + wasm32-unknown-unknown, без других языков.
- Симуляция детерминирована (Xorshift RNG). Визуальные фичи — в `render.rs`,
  логика — в `sim.rs`, UI/контролы — в `lib.rs`.
- Путь фичи: бриф в `PROJECT.md` → реализация → `cargo test` + `cargo check` + `trunk build` → коммит.

## Architecture

- `src/sim.rs` (~5700 строк) — вся логика: клетки, агенты, роли, строительство, торговля, война, религия, болезни, погода, события, тесты
- `src/render.rs` (~1150 строк) — Canvas 2D пиксель-арт, панель города, HUD
- `src/lib.rs` (~770 строк) — bootstrap, rAF-цикл, ввод (клавиатура/тач/колесо), кнопки, управление

## Key mechanics

- **Экономика**: еда/вода/руда/мясо/золото; колодцы дают воду (1.0/тик, только если в городе жители)
- **Автострой**: Well→House→Farm→TradePost→Clinic→Sanctuary→Wall→Barracks→University→Smithy→Library; only when pop > 0
- **Семьи**: 4 на город (Worker/Farmer/Miner/Hunter); переподขาดующих ролей при ≥5 жителях
- **Ресурсы**: лес регенерирует медленно (REGROW_EVERY=44); руда/вода конечны; дожди/метеориты
- **Торговля**: караваны между городами; торговые посты генерируют золото
- **Миграция**: жители уходят из голодающих городов; не едут в мёртвые (pop=0)
