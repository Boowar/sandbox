# AGENTS.md

## Current state

Rust → WebAssembly (wasm-bindgen / web-sys) проект — god-game «имитация жизни».
Сборка и dev-сервер: Trunk 0.21.x. Рендер — Canvas 2D. Ветка по умолчанию: `main`.

Все 34 пункта дорожной карты реализованы + 20 итераций улучшений + критическое исправление экономики + редизайн территории + перевод таймингов на игровые сутки (DAY_LEN=24) + реалистичная калибровка таймингов (сезон = 90 дней, человеческий жизненный цикл). 108 юнит-тестов (106 быстрых + 2 balance). Баланс оттюнен.

## Commands

- `cargo check` — быстрая проверка типов (host target)
- `cargo test` — 108 юнит-тестов
- `cargo test -- --skip balance --test-threads 8` — все тесты кроме долгого balance-теста
- `trunk build --release` — production-сборка в `dist/`
- `trunk serve` — dev-сервер с live-reload на http://localhost:8080

## Conventions

- Стек: Rust + wasm32-unknown-unknown, без других языков.
- Симуляция детерминирована (Xorshift RNG). Визуальные фичи — в `render.rs`,
  логика — в `sim.rs`, UI/контролы — в `lib.rs`.
- Путь фичи: бриф в `PROJECT.md` → реализация → `cargo test` + `cargo check` + `trunk build` → коммит.
- **Тайминги**: все интервалы событий заданы в тиках, где `DAY_LEN = 24` тиков = 1 игровой день.
  При изменении любой константы интервала (`*_EVERY`, `*_LEN`, `SEASON_LEN`) синхронно правь
  таблицу в `TIMING.md` — иначе константа и документ разъедутся.

## Architecture

- `src/sim.rs` (~7000 строк) — вся логика: клетки, агенты, роли, строительство, торговля, война, религия, болезни, погода, события, территория, тесты
- `src/render.rs` (~1490 строк) — Canvas 2D пиксель-арт, панель города, HUD, tech tree panel
- `src/lib.rs` (~930 строк) — bootstrap, rAF-цикл, ввод (тач/колесо/кнопки), управление

## Key mechanics

- **Экономика**: еда/вода/руда/мясо/рыба/золото; колодцы дают воду (1.5/тик, +50% при дожде), фермы производят еду (2.5/тик)
- **Склады** (📦): увеличивают лимиты ресурсов (+40 еда/вода, +25 руда, +20 мясо/рыба, +100 золото)
- **Старт**: 8-15 агентов/город, 600 еды/воды, 200 руды, 120 дерева
- **Расход**: голод 3.75/тик, жажда 1.25/тик (STARVE_HUNGER=480 за 5 суток, STARVE_THIRST=90 за 2 суток)
- **Автострой**: Well→House→Farm→Warehouse(70% food cap)→TradePost→Clinic→Sanctuary→Fence(во время войны)→Outpost(во время войны)→Wall→Barracks→University→Smithy→Library; only when pop > 0. Множественные фермы/колодцы, до 4 складов, 3 стены/забора, 2 казармы/кузницы/библиотеки
- **Территория**: 3 тира поселений (Settlement→Village→City с макс. радиусом 5/9/13), «ближайшая точка притяжения» побеждает — территории не накладываются; заборы/фортпосты — отдельные объекты на карте с локальными радиусами (+3/+5), дают выступы территории
- **Захват городов**: если защитников = 0 и ≥2 рейдера у центра — город захвачен
- **Забор** (🪵, кнопка 🪵): отдельный объект на краю территории, +0.05 к защите, локальный радиус +3, 15 руды, 0.5 дерева
- **Фортпост** (🗼, кнопка 🗼): отдельный объект на краю территории, локальный радиус +5, 60 руды, 2.0 дерева
- **Технологии**: 12 tech across 4 тиров; бонусы: Agriculture ×1.25 food, Construction +20% build, Warfare +0.20 def, Theology ×1.5 faith, Engineering −0.10 energy, Cartography caravan 2-step, Medicine ×0.5 plague, Metallurgy ×1.5 ore, Commerce ×0.8 prices, Philosophy +25% dev, Mastery −10% consumption
- **Погода**: дождь +50% колодцы, жара −30% фермы, мороз −30% торговля + −50% фермы
- **Календарь**: месяц 720 тиков, сезон 90 дней (2160), год 8 640 тиков; человеческий цикл: рождение раз в 9 мес., взросление в 16 по игровым годам, старость с 75 — см. `TIMING.md`
- **Ресурсы**: лес регенерирует раз в сутки (REGROW_EVERY=24); руда/вода конечны; дожди/метеориты
- **Торговля**: караваны между городами; торговые посты генерируют золото
- **Миграция**: жители уходят из голодающих городов; не едут в мёртвые (pop=0)
- **Дороги**: строятся/разбираются вручную (кнопка 🛤); нельзя на воде/горах; лес на дороге не регенерирует; ускоряют караваны/армии
- **Цветные индикаторы**: 🟢 >60%, 🟡 30-60%, 🔴 <30% заполненности ресурса
- **Визуал**: оверлеи (ночь/сезон/погода) отключены; вся информация в HUD
- **Управление**: только кнопки (клавиатура отключена). ✖ — отмена/снятие выделения, ⛰ — смена террейна застройки, 📂 — загрузка мира
- **Оптимизации**: spatial hash для поиска соседей, fire_cells для пожаров, кэш town_pop/town_has_sick
