# sandbox — имитация жизни

God-game: персонажи живут самостоятельно — собирают ресурсы, возвращают их в поселение,
отдельные сообщества растут естественно. Игрок наблюдает в реальном времени.

## Видение (долгосрочное)

- Персонажи живут сами: потребности (голод, энергия), сбор еды, поселения с запасами.
- Семьи: пары, дети, наследование к поселению.
- Войны между поселениями.
- Режим бога: смена погоды, влияние на лидеров, внушение идей отдельным персонажам.

## Текущий скоуп (MVP итерациями)

1. [x] Скаффолдинг Rust → WASM (Trunk + Canvas 2D)
2. [~] Агенты: потребности, движение, сбор ресурсов, поселения
3. [ ] Города: строительство зданий, рабочие роли
4. [ ] Семьи и размножение
5. [ ] Войны между поселениями
6. [ ] Режим бога: погода, идеи лидерам

## Технологии

- Rust → wasm32-unknown-unknown через wasm-bindgen/web-sys
- Сборка и dev-сервер: Trunk
- Рендер: Canvas 2D (террейн — на оффскрин-канвасе)

## Управление

| Ввод | Действие |
|------|----------|
| Space / кнопка ⏸ | пауза |
| + / - (клавиши или кнопки) | скорость симуляции |
| R (клавиша или кнопка) | новый мир |
| 🌱 (кнопка) | режим бога: касанием/проведением растят лес и еду |
| B (клавиша) | тот же режим на десктопе |

Полноценная работа с телефона: кнопки HUD и `pointerdown/move/up` на канвасе,
canvas масштабируется под экран (flexbox, `touch-action: none`).

## Архитектура

- `src/sim.rs` — вся логика симуляции (детерминированный Xorshift RNG, cell-генерация,
  решение агентов `decide` → `apply`, поселения, рождаемость)
- `src/render.rs` — отрисовка террейна и динамики
- `src/lib.rs` — bootstrap, цикл через requestAnimationFrame, ввод с клавиатуры
