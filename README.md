# sandbox — имитация жизни

God-game на **Rust → WebAssembly**: персонажи живут сами — ищут еду, собирают ресурсы,
носят их в поселение, растят потомство. Игрок наблюдает за миром в реальном времени
и может влиять на него как божество.

▶ **Играть:** https://boowar.github.io/sandbox/

## Возможности

- Живые агенты: голод, энергия, сбор еды, доставка в городской склад
- Поселения: запасы, рождаемость и смертность — популяции развиваются сами
- Процедурный мир: вода и леса генерируются клеточным автоматом
- **Режим бога:** касание/проведение по полю выращивает лес с едой
- Полноценное управление с телефона и компьютерной мыши
- Детерминированная симуляция (Xorshift RNG) — мир воспроизводим от seed

## Правила игры

**Ресурсы**

- **Ягоды** — растут в лесу (max 10 на клетку, восстанавливается +1 каждые 22 тика). Утоляют голод.
- **Вода** — собирается с берега водоёма (неиссякаемая). Утоляет жажду.
- **Руда** — добывается в горах (60 на клетку, не восстанавливается). Стройматериал для будущих зданий.

Жители несут собранное в городской склад (каждый вид — в свою ячейку: еда / вода / руда),
а едят и пьют дома из склада. Собирают то, чего городу не хватает сильнее всего.

**Потребности**

- Голод растёт быстрее (+1.1 за тик), жажда медленнее (+0.8). Если голод или жажда достигли 100 — житель умирает.
- Еда снимает 30 голода, вода — 30 жажды.

**Рост населения**

- Каждые 220 тиков (~17,6 с реального времени) город рождает 1 жителя, если в городе < 12 жителей,
  на складе ≥ 30 еды и ≥ 20 воды (рождение тратит 15 еды и 10 воды).
- Потолок мира — 300 жителей.

**Влияние игрока**

- Режим бога (🌱): касание/проведение переводит траву в лес с полной едой — так ты увеличиваешь запас ягод и ускоряешь рост популяции.

## Управление

| Ввод | Действие |
|------|----------|
| Space / кнопка ⏸ | пауза |
| + / - (клавиши или кнопки) | скорость симуляции |
| R (клавиша или кнопка) | новый мир |
| 🌱 (кнопка) | режим бога: касанием растят лес и еду |
| B (клавиша) | тот же режим на десктопе |

## Как запустить локально

Требуется: [Rust](https://rustup.rs) с таргетом `wasm32-unknown-unknown` и [Trunk](https://trunkrs.dev).

```bash
rustup target add wasm32-unknown-unknown
cargo install trunk     # или скачайте бинарник с releases
trunk serve             # dev-сервер на http://localhost:8080
```

Production-сборка:

```bash
trunk build --release   # результат в dist/
```

## Тесты

```bash
cargo test              # детерминизм, границы мира, еда, режим бога
```

## Деплой

Push в `main` автоматически собирает и публикует игру на GitHub Pages
([workflow](.github/workflows/deploy.yml)).

## Технологии

- **Rust** → wasm32-unknown-unknown (wasm-bindgen / web-sys)
- **Trunk** — сборка и dev-сервер
- **Canvas 2D** — рендер (террейн на оффскрин-канвасе)
